# LED 2 - Resultados de laboratorio

Esta carpeta contiene tablas y figuras generadas a partir de los scripts MATLAB del LED 2.

No se incluyen archivos .mat ni .fig debido a su tamaño. Estos archivos pueden generarse nuevamente ejecutando los códigos correspondientes.

Estructura:

- 01_Periodogram: resultados asociados al periodograma.
- 02_Welch: resultados asociados al método Welch.
- 03_Multitaper: resultados asociados al método Multitaper.
- 04_Comparativa: resultados comparativos entre métodos.
