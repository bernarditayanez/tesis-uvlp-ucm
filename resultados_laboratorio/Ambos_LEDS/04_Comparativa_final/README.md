# Ambos LEDS - Comparativa final

Resultados generados por el script A_LEDS_04_comparativa_final_v4.m.

Esta etapa compara los resultados obtenidos mediante Periodograma, Welch y Multitaper para ambos LED encendidos simultáneamente. Además, incluye la comparación entre las frecuencias obtenidas en el análisis individual y en el análisis simultáneo.

Para reproducir esta etapa, primero deben ejecutarse los scripts individuales de Periodograma, Welch y Multitaper.

Se incluyen tablas .csv y figuras .png. Los archivos .mat y .fig no se incluyen debido a su tamaño.
