# LED 1 - Códigos de laboratorio

Esta carpeta contiene los scripts MATLAB utilizados para el análisis espectral del LED 1 en laboratorio.

Orden de ejecución:

1. LED1_01_periodogram_final_graficas_v2.m
2. LED1_02_welch_final_graficas_v2.m
3. LED1_03_multitaper_V2_afinada_local.m
4. LED1_04_comparativa_local_56kHz_version_A.m

Los tres primeros scripts generan resultados individuales mediante Periodograma, Welch y Multitaper. El cuarto script realiza la comparación final entre métodos, por lo que debe ejecutarse después de los anteriores.
