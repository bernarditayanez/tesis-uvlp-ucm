# P3 - LED terreno 3

Esta carpeta contiene los scripts MATLAB utilizados para el análisis espectral del punto de medición P3, asociado al LED 3 en terreno.

## Orden de ejecución

1. `T07_P3_periodogram_terreno.m`
2. `T08_P3_welch_terreno.m`
3. `T09_P3_multitaper_terreno.m`

El Periodograma se utiliza como método principal de detección. Welch y Multitaper se emplean como métodos complementarios.

## Datos de entrada

Los scripts utilizan archivos ON correspondientes al punto P3 y archivos OFF comunes para los análisis de terreno.

Los archivos CSV originales no se incluyen en GitHub debido a su tamaño.

## Ejecución

Antes de ejecutar cada script, se deben modificar las rutas locales indicadas al inicio del archivo MATLAB.
