# P3 - LED terreno 3

Scripts MATLAB para el análisis espectral del punto P3, asociado al LED terreno 3.

## Orden de ejecución

1. T07_P3_periodogram_terreno.m
2. T08_P3_welch_terreno.m
3. T09_P3_multitaper_terreno.m

## Scripts

- T07_P3_periodogram_terreno.m: análisis mediante Periodograma.
- T08_P3_welch_terreno.m: análisis mediante Welch.
- T09_P3_multitaper_terreno.m: análisis mediante Multitaper.

## Archivos

- ON: archivos de la carpeta Terreno_ON_M3.
- OFF: archivos comunes de la carpeta Terreno_OFF.
