# P2 - LED terreno 2

Scripts MATLAB para el análisis espectral del punto P2, asociado al LED terreno 2.

## Orden de ejecución

1. T04_P2_periodogram_terreno.m
2. T05_P2_welch_terreno.m
3. T06_P2_multitaper_terreno.m

## Scripts

- T04_P2_periodogram_terreno.m: análisis mediante Periodograma.
- T05_P2_welch_terreno.m: análisis mediante Welch.
- T06_P2_multitaper_terreno.m: análisis mediante Multitaper.

## Archivos

- ON: archivos de la carpeta Terreno_ON_M2.
- OFF: archivos comunes de la carpeta Terreno_OFF.
