# P2 - LED terreno 2

Esta carpeta contiene los scripts MATLAB utilizados para el análisis espectral del punto de medición P2, asociado al LED 2 en terreno.

## Orden de ejecución

1. `T04_P2_periodogram_terreno.m`
2. `T05_P2_welch_terreno.m`
3. `T06_P2_multitaper_terreno.m`

El Periodograma se utiliza como método principal de detección. Welch y Multitaper se emplean como métodos complementarios.

## Datos de entrada

Los scripts utilizan archivos ON correspondientes al punto P2 y archivos OFF comunes para los análisis de terreno.

Los archivos CSV originales no se incluyen en GitHub debido a su tamaño.

## Ejecución

Antes de ejecutar cada script, se deben modificar las rutas locales indicadas al inicio del archivo MATLAB.
