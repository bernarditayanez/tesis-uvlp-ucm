# Códigos complementarios

Esta carpeta contiene códigos utilizados como apoyo metodológico durante el desarrollo del trabajo.

Los scripts incluidos no forman parte del flujo principal de análisis validado de laboratorio. Se incorporan como material complementario para documentar ejemplos de procesamiento y decisiones metodológicas tomadas durante el desarrollo experimental.

Estructura:

- ejemplo_senal_senoidal: código utilizado para generar una señal senoidal de ejemplo en el escrito.
- codigo_descartado_MT_LED1_78kHz: versión descartada del análisis Multitaper del LED 1, conservada como respaldo metodológico.
