# Ejemplo de señal senoidal

Esta carpeta contiene el código MATLAB utilizado para generar una señal senoidal de ejemplo incorporada en el escrito.

El objetivo de este código es únicamente ilustrativo, ya que permite representar de forma simple la lógica de análisis temporal y espectral aplicada posteriormente a señales experimentales reales.

Este script no corresponde a una medición experimental del sistema uVLP.
