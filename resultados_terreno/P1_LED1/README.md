# P1 - LED terreno 1

Esta carpeta contiene los resultados obtenidos del análisis espectral del punto de medición P1, asociado al LED 1 en terreno.

## Estructura

- `01_Periodogram`: resultados obtenidos mediante Periodograma.
- `02_Welch`: resultados obtenidos mediante Welch.
- `03_Multitaper`: resultados obtenidos mediante Multitaper.

Los archivos CSV originales adquiridos desde el osciloscopio no se incluyen en GitHub debido a su tamaño.
